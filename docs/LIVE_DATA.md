# 실제 시세와 뉴스

v0.1.2부터 Market Room의 기본 공급자는 실제 외부 데이터입니다. 기존 Mock 공급자는 테스트·예시 테마·Game Atelier에만 남아 있습니다.

- 국내 관심 종목: 네이버 금융 공개 웹 시세. 장애 시 Yahoo Finance의 지연 시세로 전환하며 화면에 출처와 지연을 표시합니다.
- 미국 관심 종목, 지수, OHLCV 차트: Yahoo Finance 공개 웹 데이터.
- 뉴스: Google News RSS의 국내·미국 기업, 산업, 경제, 정책 검색 피드. 제목·언론사·발행 시각·기사 링크만 수집합니다. 분류는 검색어 기준이며 기사 내용을 분석한 결과가 아닙니다.
- 현재 관심 종목은 삼성전자, SK하이닉스, 현대차, NAVER, 한화에어로스페이스, Apple, Microsoft, NVIDIA, Tesla, Alphabet, Amazon입니다.

## 갱신과 시각

앱이 실행 중인 동안 시세를 1분, 뉴스를 5분 간격으로 확인합니다. 창을 다시 보거나 포커스·네트워크가 복구되면 즉시 확인합니다. 중복 요청을 합치고 공급처 캐시와 권장 pollingInterval을 지킵니다. 따라서 화면 확인 주기와 공급처의 실제 갱신 주기는 다를 수 있습니다.

시세 기준 시각(updatedAt), 실제 수신 시각(fetchedAt), 화면의 마지막 성공 확인 시각은 별도로 다룹니다. 휴장 중에는 마지막 거래 가격과 날짜가 유지됩니다. 네이버 시간외 가격은 Yahoo 정규장 차트의 마지막 가격과 다를 수 있습니다.

Yahoo 국내 주식·지수는 약 20분, VIX는 약 15분 지연으로 표시합니다. 미국 Nasdaq 데이터의 제공처 지연 표기는 0분입니다. 초 단위 거래소 스트리밍이나 체결가를 보장하지 않습니다. Yahoo 공식 지연 안내: https://help.yahoo.com/kb/SLN2310.html

연결 실패 시 새 가상 데이터를 만들지 않습니다. 화면에 마지막 성공 데이터와 갱신 실패를 표시합니다. 일부 종목·지수만 실패하면 사용 가능한 결과를 표시하고 누락 항목을 알립니다. 뉴스 피드 요청이 실패하면 이전 목록과 실패 상태를 유지합니다.

## 네트워크 경계

외부 통신은 Electron Main의 고정된 HTTPS 공급처에서만 수행합니다. Renderer에는 종목·기간·뉴스 필터·기사 ID를 받는 명시적 IPC만 노출합니다. 기존 송신자 검증, sandbox, CSP를 유지합니다.

뉴스 원문 열기는 Main이 현재 세션에서 확인한 ID를 Google News 기사 링크로 해석한 뒤 기본 브라우저에서 엽니다. 임의 URL, 로컬 파일, 실행 명령은 전달할 수 없습니다. RSS는 크기·시간 제한을 적용하고 DTD/ENTITY 선언을 거절합니다. 뉴스 HTML이나 원문을 앱에서 실행하지 않습니다.

API 키나 로그인은 사용하지 않습니다. 웹 공개 엔드포인트는 공식 개발자 API 계약이 아니므로 구조 변경·접근 제한·일시 장애가 생길 수 있습니다. 이 경우 오류로 표시하며 계정이나 유료 서비스에 자동 가입하지 않습니다.

## 검증

테스트는 실제 응답 형태의 고정 표본으로 파싱, 통화·종목 일치, 날짜·가격 검증, 지연 출처, 캐시·중복 요청, 부분 장애, 네트워크 오류, RSS 중복·정렬·외부 링크 제한, 주기 갱신 중복 방지와 숨김·종료 처리를 확인합니다. 네트워크 실측은 별도로 실행하며 CI 테스트가 외부 시세에 의존하지 않게 유지합니다.
