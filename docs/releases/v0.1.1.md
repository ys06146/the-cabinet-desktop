# The Cabinet v0.1.1

Windows x64용 첫 공개 설치 버전입니다.

## 변경 내용

- 투자 리서치를 정리하는 Market Room과 게임 기획·편집·Canvas Preview를 제공하는 Game Atelier.
- 앱 상단의 **자동 업데이트** 버튼: 새 버전 확인 후 다운로드와 재시작 설치를 선택할 수 있습니다.
- 투자 메모·게임 프로젝트의 로컬 저장과 종료·업데이트 전 저장 확인.
- Windows CI에 맞춘 소스 줄바꿈 통일.

## 설치 및 업데이트

`The-Cabinet-Setup-0.1.1.exe`를 내려받아 설치하세요. 기존 0.1.0보다 높은 버전이며, 사용자 데이터는 앱 설치 파일과 분리해 저장합니다.

업데이트용 `latest.yml`과 EXE blockmap을 함께 게시합니다. 기존 설치본에서 실제 자동 다운로드·설치 및 데이터 보존을 검증한 결과는 아직 없습니다.

## 알려진 한계

- 코드 서명 인증서가 없는 초기 배포판으로, Windows SmartScreen 또는 알 수 없는 게시자 경고가 표시될 수 있습니다.
- 시장 데이터·뉴스·AI 응답은 모의 데이터입니다. 실제 금융·LLM·Unity API는 연결되지 않았습니다.
- 설치 중 실패 후 복구, Windows 배율·계정별 호환성의 전체 VM 수용 시험은 완료되지 않았습니다.
- Game Project JSON 내보내기·가져오기는 지원하지 않습니다.

## 검증

lint·TypeScript·213개 단위 테스트·production build·Windows x64 NSIS 패키징을 통과했습니다. 게시 후 익명 다운로드한 설치 파일의 크기와 SHA-512를 latest.yml과 대조했으며, blockmap의 파일 크기도 일치합니다.
