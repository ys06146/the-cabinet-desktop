# The Cabinet v0.1.2

삼성전자와 다른 종목 가격 및 뉴스가 고정된 예시 데이터로 표시되던 문제를 수정했습니다.

- 국내·미국 11개 관심 종목과 시장 지수, 차트를 실제 데이터에 연결했습니다.
- 앱 실행 중 시세는 1분, 뉴스는 5분마다 확인합니다. 다시 활성화하거나 네트워크가 복구되면 갱신합니다.
- 출처, 거래 기준 시각, 수신 시각, 지연 여부를 표시합니다. 휴장 중에는 최근 거래 가격이 유지됩니다.
- 뉴스 제목·언론사·발행 시각을 갱신하고 기본 브라우저에서 원문을 열 수 있습니다.
- 연결 실패 시 이전 데이터를 유지하며 오류를 알립니다. 실제 기사에 가상 요약·감성·투자 영향 평가를 붙이지 않습니다.

국내 차트는 Yahoo Finance 기준 약 20분 지연될 수 있으며, 네이버 시간외 가격과 정규장 차트가 다를 수 있습니다. Game Atelier AI와 투자 테마는 예시 기능으로 남아 있습니다. 공개 웹 피드는 제공처 변경이나 제한의 영향을 받을 수 있습니다.

Windows x64 설치 파일과 자동 업데이트용 blockmap·latest.yml을 제공합니다. 기존 앱의 **자동 업데이트** 버튼에서 확인·다운로드 후 재시작 설치할 수 있습니다. 코드 서명은 아직 적용되지 않았습니다.
